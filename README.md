# Ziad & Hana

A static engagement invitation for GitHub Pages.

## Local Use

Open `index.html` in a browser. No server, Node.js, or installation is required.

RSVPs are saved in the browser's local storage. Each RSVP opens a prefilled
WhatsApp message. GitHub Pages cannot provide a shared database, so the guest
counter reflects RSVPs saved on the current device and browser.

## Publish On GitHub Pages

1. Upload the contents of this folder to a GitHub repository.
2. Open the repository's **Settings**, then **Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Open the GitHub Pages URL after deployment finishes.

The site uses relative paths, so it works from a repository URL such as
`https://USERNAME.github.io/REPOSITORY/`.
